## Selection Sort:- 
Selection sort is a sorting algorithm where we select the minimum or smallest element and we place it at it's correct position

~ Time Complexity  O(time) = O(n^2) /
Space Complexity O(space) = O(1)

## Insertion Sort:- 
Insertion sort is a sorting machenism where the pivot element is inserted at its right position and sorting is achieved.

~ Time Complexity  O(time) = O(n^2) /
Space Complexity O(space) = O(1)

## Bubble Sort:-
Bubble sort is a sorting machenism where we compare to connected elements and if the first element is bigger element than the second element than we swap the elements and sorting is achived in this way.

~ Time Complexity  O(time) = O(n^2) /
Space Complexity O(space) = O(1)
